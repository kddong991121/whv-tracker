# 결정 기록 (2026-11-10) — PRD v4 반영 지시

작성: 사용자(대표) 결정, 참모 정리. 이 문서를 근거로 docs/PRD.md를 v4로 갱신한다.

## 1. 배포 전제 변경
- 기존 "로컬 PC 전용, 배포 안 함"을 폐기한다. **실제 공개 배포**를 목표로 한다.
- 저장 방식은 **혼합형**:
  - 근무 기록(날짜, 근무 시간, 고용주, 포스트코드, 업무 유형)은 **서버(DB)에 저장**. 회원 계정 단위.
  - 페이슬립 PDF 원본은 **서버로 전송하지 않는다.** 사용자 브라우저에서 읽고(예: pdf.js), 고용주명·ABN·급여 기간·총 시간만 추출해 사용자가 확인 후 서버로 보낸다. 원본은 사용자 기기에만 둔다.
- 새로 필요한 범위: 회원가입·로그인(이메일 또는 구글), 개인정보 처리방침·이용약관 페이지, Spring Security(CSRF 포함), 배포 환경. 호스팅은 무료 구간 서비스 후보를 조사해 비교 보고(결정 전 확정 금지).
- 비용 원칙: 가능한 0원. 유료가 필요해지면 사용자 승인 후.

## 2. 데이터 구조 변경: "하루 = 여러 근무"
- 고용 형태(풀타임/캐주얼/파트타임)는 **계산에 쓰지 않는다.** 메모용 표시로만 둔다.
- 세는 방식은 두 가지:
  - **매일 출근하는 정규 근무**(기존 모드 A): 시작일~종료일, 주말 포함 달력일.
  - **일한 날만 기록**(기존 모드 B): 날짜 1개에 근무(shift) 여러 개. 각 근무 = 고용주 + 시간.
- 같은 날은 고용주가 몇 곳이든 **1일을 넘지 않는다**(원문 "Normal work days or shifts").
- 고용주마다 **정상 근무 시간(시간/일)**과 **업무 유형**을 등록받는다.
  - 업무 유형 질문 예: "수확·포장 등 바로 하는 작업"(인정) / "소시지·와인 제조 등 가공품 제조"(불인정, 원문 2차 가공).
- 하루 판정:
  - 인정 지역·인정 업무 근무 하나가 그 고용주의 정상 시간 이상 → **확실**
  - 정상 시간보다 짧음 → **짧게 일한 날(인정 안 될 수도 있어요)**
  - 여러 곳 시간을 합쳐야 정상 시간이 되는 날 → **짧게 일한 날**과 같은 분류(원문에 합산 기준 없음)
  - 인정 지역·업무가 아닌 근무 시간은 판정에서 제외
- 홈의 큰 숫자는 **확실한 일수만**, 정수로 내림 표시. 짧게 일한 날은 별도로 보여준다.

## 3. 화면 용어 (사용자 화면에 쓰는 말)
| 쓰지 않음 | 사용 |
|---|---|
| specified work, 2년차/3년차 조건 | 세컨 비자 인정 근무, 서드 비자 |
| 환산일, 달력일, W | 숨김. "N일 인정"으로만 표시 |
| 모드 A / 모드 B, 풀타임/캐주얼(계산 의미) | 매일 출근하는 정규 근무 / 일한 날만 기록 |
| 확인 필요 | 짧게 일한 날 – 인정 안 될 수도 있어요 |
| span, 기간 조건 | 시작한 지 3개월(88일)이 지나야 신청할 수 있어요 |
| 1차/2차 가공 | 수확·포장 = 인정 / 가공품 제조 = 불인정 |
| 포스트코드 인정 지역 | 세컨 인정 지역 |
- 소수점은 상세 화면에서만. 홈 요약은 정수(내림).
- 앱 이름·문구 최종안은 나중에 정한다. 용어는 위 표로 통일.
