# 2026-11-12 재방문 지표 추가

## 상황
- 가입자 22명. 가입만 하고 다시 안 오는지, 계속 쓰는지 알 방법이 없다.
- 다시 쓰게 하는 알림(웹 푸시)을 검토했지만, 효과를 잴 기준이 먼저 필요하다.

## 결정
- /admin에 재방문 숫자 3개 추가 (PRD 4.9b).
- `work_day.created_at` 칸 추가 (Flyway V11).
- 알림은 일주일 숫자를 본 뒤 결정. 만든다면 주 1회 기본, 매일은 선택, 사용자가 허용한 경우만.

## 고르지 않은 것
- 방문 기록 표(날짜별 방문 로그): 주별 흐름까지 보이지만 저장량과 개인정보 부담이 커서 지금은 과하다.
- 알림 먼저 만들기: 효과를 비교할 기준선이 없다. 아이폰은 홈 화면 추가가 필요해 받는 사람이 적을 수 있다.
