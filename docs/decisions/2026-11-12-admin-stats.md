# 결정: 운영 통계 화면 /admin (2026-11-12)

- 상태: 승인 (사용자 채팅 "오키", 2026-11-12 12:09 KST)
- 배경: 가입자 수를 보려면 매번 SSH로 SQL을 쳐야 했다. 폰에서는 붙여넣기도 잘 안 된다.

## 결정
1. `/admin`: 관리자 이메일(WHV_ADMIN_EMAIL)로 로그인한 경우에만 연다. 나머지는 404.
2. 숫자만 보여준다. 개인정보는 보여주지 않는다.
3. "다시 온 사람"은 로그인 시각이 아니라 방문 시각(`last_seen_at`)으로 센다. 로그인이 30일 유지되기 때문이다. 요청마다 쓰지 않고 하루 한 번만 쓴다.
4. 탈퇴 수는 `deleted_account_log`에 시각만 남겨서 센다.
