# 결정: 근무 기록 편의 기능 묶음 (2026-11-12)

- 상태: 승인 (사용자 채팅 "그렇게하자" → 변경안 → 칩 4/6/8시간으로 수정 → "네", 2026-11-12 09:48 KST)
- 배경: 토스·카카오톡처럼 "입력을 거의 안 하게" 만드는 것이 목표. 기능 개수(5개)는 그대로이고 F1을 보강한다.

## 결정
1. 원탭 기록 (홈): 마지막 근무 일터 · 평소 시간 · 오늘. 이미 있으면 "기록 완료 ✓".
2. 지난주 그대로 넣기 (근무 기록 주간 화면). 규칙 위반 날은 건너뛰고 수를 알린다.
3. 로그인 유지 30일: Spring Session JDBC, Flyway V9 (SPRING_SESSION 표 2개).
4. 되돌리기: 삭제 후 5초 토스트. DB 구조 변경 없음 (같은 값으로 다시 추가).
5. 시간 칩 4·6·8시간 (사용자 지정). 평소 시간보다 짧으면 안내. 숫자 키패드.
