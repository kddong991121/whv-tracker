# 결정: 포스트코드 입력 시 지역명을 참고로 보여준다 (2026-11-11)

- 상태: 진행 (사용자 제안 "4350 입력하면 Toowoomba", 자료 파일 제공 "넣었어", 2026-11-11 15:32 KST)
- 자료: ABS SAL 2021 – POA 2021 – MMM 2023 (data.gov.au, CC BY 2.5 AU). 무료이며 외부 API 호출 없음 (비용 0원 규칙 충족).

## 결정
1. 인정 지역 확인, 일터 추가 폼에서 포스트코드 입력 시 "대표 지역명 (주) · 동네 3개 외 N곳"을 보여준다.
2. 지역명은 판정에 쓰지 않는다 (ABS 경계는 통계용 근사치). 화면에 출처와 "참고용"을 적는다.
3. 엑셀 원본은 docs/sources/에 두고, 변환 스크립트(build_localities.py)로 앱용 CSV를 만든다 (재현 가능).
4. 기능 개수는 그대로 (F2 화면 보강).
