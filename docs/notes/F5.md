# F5 비자 만료일까지 남은 기간과 페이스

## 만든 것 (2026-11-10)
- `/ledger` 맨 위에 "비자 만료일까지" 카드. 1년차 비자 만료일과 버퍼 일수를 저장하면 (계정별, Flyway V6 `users.visa_expiry`, `users.buffer_days`) 아래를 보여준다.
  - 완료 목표일 = 만료일 − 버퍼 일수 (사용자 목표, 규정상 기한 아님).
  - 남은 기간 R = 완료 목표일 − 오늘.
  - 더 필요한 인정 일수 N = 88 − 홈 표시 인정 일수 (정수 내림 기준, 최소 0).
  - 일주일에 필요한 인정 일수 = N ÷ R × 7 (소수 첫째 자리 반올림). R ≤ 0이면 "계산할 수 없어요".
  - D-120/90/60/30 알림 문구 (앱을 열 때 계산, 푸시·이메일 없음).
  - 만료일 경과 → "비자 만료일이 지났는지 확인해 주세요", 88일 달성 → "목표 달성" (둘 다 알림 대신).
  - 완료 목표일까지 가도 첫 인정일부터 88일이 안 되면 → "시작한 지 3개월(88일)이 지나야 신청할 수 있어요".
- 계산은 `calc.PacePlan` (순수 Java). 첫 인정일을 쓰려고 `VisaSummary`에 `firstDate`를 추가했다.

## 핵심 코드 설명 (면접 대비)
- 날짜 계산은 서버의 `LocalDate.now()`를 컨트롤러에서 한 번만 읽고 `PacePlan.of(..., today, ...)`에 넘긴다. 계산 클래스가 시계를 직접 읽지 않아서 테스트에서 날짜를 고정할 수 있다.
- 배포 서버 시간대가 호주가 아니면 "오늘"이 하루 어긋날 수 있다. 배포 단계에서 시간대를 정한다.

## 테스트 (필수)
- 주당 필요량 공식과 알림 단계, 버퍼와 R = 0, 만료·목표 달성 시 알림 숨김, 88일 기간 부족 경고, 음수 버퍼 거부, 저장·화면 표시.

## 남은 것
- 88일 착수 기한 역산은 PRD대로 MVP에서 뺐다 (7절 6번).
- 서드 비자(179일) 페이스는 아직 없다. 세컨만 계산한다.
