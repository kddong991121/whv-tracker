# F1 상태 메모 (현재)

- 상태: F1 v3 코드를 백업에서 복원하고, 계정 단위로 옮겼다. 커밋 전이다.
- 계산: `calc` 패키지는 v3 그대로 (달력일, 모드 B 환산 7÷W, 상한, 교차 중복, 2019 기준). v4 계산은 아직 아니다.
- 저장: `work_record`에 `owner_user_id` (users FK). 모든 조회·저장은 로그인 계정 기준이다.
- 화면: 근무 기록은 `/ledger`. 홈 `/`은 로그인 상태 안내만 한다.
- 데모: 데모 계정 기록이 비었을 때 샘플 3건을 넣는다.
- 마이그레이션: V1 `users`, V2 `work_record` (owner FK 포함), V3 `work_day`·`work_standard_change`.

## 남은 차이 (v4 대비)
- 근무 기록 구조는 v3 (모드 A/B, 날짜당 1행). v4의 shift 구조와 정상 근무 시간, 업무 유형, 확실/짧게 일한 날 판정은 없다.
- 홈 정수 내림 표시, 용어 표 교체, 고용 형태 메모 필드 모두 없다.
- 테스트 기대값은 v3 그대로다. 리다이렉트 경로만 `/`에서 `/ledger`로 바뀌었다.
