# F4 근무 이력 PDF 내보내기

## 만든 것 (2026-11-10)
- 화면 `/export` (홈 "일한 곳" 옆 "PDF" 링크): 영문 이름, 기간, 넣을 일터를 고르고 "PDF 받기".
  - 영문 이름은 PDF에만 쓰고 저장하지 않는다. 여권 영문 형식(영문자, 공백, `.'-`)만 받는다.
- `/export/pdf`: 서버에서 OpenPDF(LGPL 2.1 / MPL 2.0)로 만든 A4 가로 영문 PDF를 내려받는다.
  - 요약표 (세컨·서드): 정규 근무 달력일, 일한 날 환산(x 7 / 5), 합계, 짧게 일한 날(합계 제외), 기록한 시간, 일터 수.
  - 일터 표: 이름, ABN(페이슬립에서 읽은 값), 포스트코드, 기간, 차수, 업종/작업 종류, 일한 양, 인정 지역 확인 결과와 페이슬립 체크리스트 점수.
  - 규칙과 근거 표: 사용한 규칙, 원문 절 제목, 근거 상태 (Official text / Needs confirmation), 출처 URL과 조사일.
  - 모든 페이지 아래 영문·한국어 면책 문구. 인정 일수가 0이면 "기록 부족 / INSUFFICIENT RECORDS" 워터마크.
- 기간을 고르면 정규 근무 기간과 일한 날 기록을 그 기간으로 잘라서 다시 계산한다 (`LedgerService.dashboard(owner, ids, from, to)`).
- 한글 글꼴: `resources/fonts/NanumGothic.ttf` (나눔고딕, SIL OFL 1.1)를 PDF 안에 넣는다. 보는 사람 PC에 한글 글꼴이 없어도 보인다.

## 핵심 코드 설명 (면접 대비)
- 화면용 계산과 PDF용 계산이 같은 `WorkCalculator`를 쓴다. PDF는 입력(기간, 일터)만 걸러서 넘긴다. 계산 규칙이 한 곳에만 있다.
- 면책 문구는 `PdfPageEventHelper.onEndPage`로 모든 페이지에 찍는다. 표가 여러 페이지로 넘어가도 빠지지 않는다.
- PDF 받기는 상태를 바꾸지 않으므로 GET이다 (CSRF 대상 아님).

## 테스트 (필수)
- PDF 텍스트에 이름, 일터, 기간으로 자른 달력일(3월 = 31일), 영문 면책 문구가 들어가는지.
- 한글 이름 거부.
- 실제 데모 데이터로 PDF를 만들어 화면으로 확인 (한글 일터 이름, 한국어 면책 문구 표시).

## 남은 것
- 근무지 주소는 저장하지 않아 포스트코드만 적는다.
- "specified work" 영문 용어 유지는 PRD 7절 17번 확인 필요.
