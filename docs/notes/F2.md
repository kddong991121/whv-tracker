# F2 세컨 인정 지역 확인

## 만든 것 (2026-11-10)
- 화면 `/check`: 포스트코드 + 업종 (+ 농장 작업 종류, 재해 복구 유급/봉사, 신청 예정일)을 넣으면 결과를 보여준다.
  - 로그인 없이 누구나 쓸 수 있다 (`SecurityConfig` 공개 경로). 입력값은 저장하지 않는다.
  - 홈에 링크를 달았다.
- 시드: `docs/seed/specified_work_postcodes.csv`를 `src/main/resources/seed/`로 복사했다. 원본은 수정하지 않았다.

## 판정 순서 (`EligibilityService.check`)
1. 주 후보: 시드 CSV의 `state` 우선. CSV에 없으면 번호대 표 (`StateRanges`, PRD 4.3a). 2899는 NSW.
2. 코로나 의료는 표 없이 전국 인정 (근무 2020-01-31 이후 조건 문장 표시).
3. 농장 일인데 작업 종류가 가공품 제조·정원 관리면 → "인정 업무가 아니에요".
4. 일치 행 = 포스트코드에 직접 적힌 행 + 주 전체(`ALL`) 행 (업종이 같은 것만).
5. 일치 행이 없으면 → "목록에서 찾지 못했어요 (확인 불가)". 인정이라고 단정하지 않는다.
6. 행마다 판정 후 가장 유리한 결과를 고른다.
   - 신청 예정일이 표 조건(`lodged from ...`)보다 빠르면 → 조건 미충족.
   - 표 6 (재해 복구)인데 유급/봉사를 고르지 않았으면 → 조건부.
- 여러 주에 걸친 포스트코드 (예: 0872)는 주 목록을 함께 보여주고 "주에 따라 다를 수 있어요"라고 표시한다.

## 핵심 코드 설명 (면접 대비)
- 5,765행 CSV를 기동 시 한 번 읽어 `Map<포스트코드, 행 목록>`과 `Map<주, ALL 행 목록>` 두 개로 나눠 둔다. 조회는 해시 조회 두 번이라 빠르고, DB가 필요 없다.
- 판정 결과를 enum 순서(유리한 결과가 앞)로 정해 두고 `ordinal()` 비교로 "가장 유리한 결과"를 고른다. if 분기를 줄이기 위해서다.
- 근무 날짜 조건 ("work from 2021-06-22" 등)은 판정에 쓰지 않고 문장으로 보여준다. 근무 기록(F1)과 연결은 다음 단계다.
