# F3 페이슬립 가져오기와 증빙 체크리스트

## 만든 것 (2026-11-10)
- 화면 `/payslip` (하단 메뉴 "페이슬립").
  1. PDF 고르기 → **브라우저에서만** pdf.js로 글자를 읽는다. 파일 입력칸은 `name`이 없고 폼 밖에 있어서 서버로 가지 않는다.
  2. 고용주, ABN, 급여 기간, 총 근무 시간, 고용 형태(참고용)를 자동으로 채운다. 사용자가 확인하고 고친다.
  3. 급여 기간의 날짜 칸이 나오고 (평일 기본 선택), 일한 날을 고른다. 총 시간을 고른 날 수로 똑같이 나눠 넣는다.
  4. 증빙 체크리스트 7개 (선택), 현금 지급 체크 (선택), 저장 동의 (필수) → 저장.
- 서버 (`PayslipService.importPayslip`)는 읽은 값만 받아 `payslip` 테이블(Flyway V7)에 저장하고, 고른 날짜마다 일한 날 근무를 만든다.
  - 하나라도 실패하면 (같은 날짜 중복, 하루 24시간 초과 등) 트랜잭션으로 전부 되돌린다.
  - ABN은 선택이며, 넣으면 체크섬을 검사한다 (입력 검증, 규정 요건 아님).
- pdf.js는 CDN이 아니라 Maven 의존성 `org.webjars.npm:pdfjs-dist:5.7.284`로 앱 안에서 제공한다 (`/webjars/...`). 제3자 서버로 요청이 가지 않는다.
- 사진(JPG·PNG) PDF나 글자가 없는 PDF는 "글자를 읽지 못했어요" 안내 후 직접 입력한다.

## 읽는 규칙 (화면 스크립트 `parse`)
- ABN: `ABN` 뒤 숫자 11자리. 고용주: ABN 줄 앞 글자 또는 바로 윗줄, 없으면 첫 줄.
- 급여 기간: `dd/mm/yyyy - dd/mm/yyyy` (호주 표기, `to`·`–`도 허용).
- 총 근무 시간: `Total Hours`, `Hours Worked`, `Ordinary Hours` 뒤 숫자.
- 고용 형태: Casual / Full-time / Part-time.
- 페이슬립 양식이 회사마다 달라서 자동 입력은 "제안"이고, 저장 전에 사용자가 꼭 확인한다.

## 핵심 코드 설명 (면접 대비)
- 개인정보 최소 수집: TFN·계좌번호가 있는 원본을 서버에 두지 않으려고 파싱을 클라이언트로 옮겼다. 서버 코드에 multipart 업로드가 없다.
- 여러 근무 행을 한 트랜잭션에서 만들고, 중간에 예외가 나면 롤백되어 "반쯤 저장된" 상태가 생기지 않는다.

## 테스트 (필수)
- 저장 시 근무 행 생성과 시간 균등 분배 (30.5시간 ÷ 4일 = 7.63), 동의 필수, 기간 밖 날짜 거부, ABN 체크섬, 중복 날짜 시 전체 롤백, 화면에 업로드 필드 없음.
- 실제 Chrome에서 예시 PDF로 자동 입력 확인 (고용주, ABN, 기간, 시간, 고용 형태).

## 남은 것
- 저장한 페이슬립 수정·삭제.
- 사진 페이슬립 자동 읽기 (OCR)는 MVP 밖.
