# 화면 (시안 기준, 2026-11-10)

시안: `docs/design/` (Main, Daily). 색과 카드 모양은 시안을 따른다. 공통 스타일과 하단 메뉴는 `templates/fragments/ui.html`.

## 화면
- **홈 `/`** (로그인 시, 로그아웃 상태는 기존 소개 화면 `index`)
  - "세컨 비자까지 N일 남았어요" + 큰 숫자 "N일 / 88일" (정수 내림).
  - 진행 막대: 인정된 날(파랑) + 짧게 일한 날(노란 빗금). 짧게 일한 날이 있으면 노란 안내.
  - "시작한 지 N일 · 3개월(88일)이 지나야 신청할 수 있어요".
  - 비자 만료까지 D-day, 일주일에 필요한 날 (F5). 만료일이 없으면 입력 안내.
  - 이번 달 달력 (매일 출근 / 일한 날 / 짧게 일한 날), 일한 곳 목록, "+ 근무 추가" 버튼.
- **근무 기록 `/work`** (시안 Daily)
  - 내 일터 목록과 "+ 일터 추가" (일한 날 기록 일터, 세컨·주 5일 기준으로 저장).
  - 주간 보기: 날짜마다 여러 일터 근무, "+ 근무"로 추가, ✕로 삭제. 날짜 배지: 인정 / 짧게 일한 날 / 쉬는 날 / 합계 제외.
  - 아래 요약: 일한 날, 인정, 짧게 일한 날.
- **하단 메뉴**: 홈 / 근무 기록 / 인정 지역(`/check`) / 상세(`/ledger`, 기존 전체 입력 화면).
  - 시안의 "페이슬립" 탭은 F3 단계에서 바꾼다.

## 핵심 코드 설명 (면접 대비)
- 서버 렌더링(Thymeleaf)이라 시안의 −/+ 버튼 대신 "추가" 폼과 "✕" 삭제 폼으로 만들었다. 모든 폼은 POST + CSRF 토큰이다.
- 달력 칸은 `LedgerService.calendar`가 날짜별 종류를 만들고, 컨트롤러가 앞쪽 빈칸(일요일 시작)을 붙여 그린다.
- 삭제는 본인 기록인지 확인한 뒤 지운다 (`deleteWorkDay`). 다른 사람 근무 id를 넣으면 "찾을 수 없습니다".

## 테스트 (필수)
- 홈: 진행 문구, 짧게 일한 날 안내, 일한 곳, 면책 문구.
- 근무 기록: 근무 추가 → 주간 화면에 표시 → 삭제.

## 남은 것
- 매일 출근 기간 입력은 아직 `/ledger` 상세 화면에만 있다.
- `/ledger`, `/check`, `/account` 화면은 아직 예전 모양이다.
