# 처음 온 사람 안내 (2026-11-12)

```
가입 직후 홈
┌ 처음이세요? 3단계면 끝나요 ───────┐
│ ✓ 준비 중인 비자 [세컨] [서드]     │
│ ② 일한 곳 추가 (이름·포스트코드…)  │ ─ 저장 → POST /work/place?next=home → 홈
│ 3 첫 근무 넣기                      │
└──────────────────────────────────┘
          ↓
│ ✓ 일한 곳 추가 · Sunny Farm         │
│ ③ Sunny Farm에서 언제 일했나요?     │
│   [어제 8시간] [오늘 8시간]          │ ─ POST /work/shift?next=home → 홈
          ↓ 근무 1개 생기면 카드 사라짐 (원탭 버튼·달력이 그 자리를 이어받음)
```

## 핵심 코드 설명 (면접 대비)
1. **상태 기반 단계:** "안내를 몇 단계까지 봤는지"를 저장하지 않고, 실제 데이터(일터 유무, 근무 유무)로 단계를 계산한다(`LedgerService.onboarding`). 저장할 상태가 없으니 어긋날 일도 없다. 다른 기기에서 일터를 넣어도 바로 맞게 보인다.
2. **열린 리다이렉트 방지:** 저장 후 돌아갈 곳을 요청 값으로 받지만 `"home"`이라는 정해진 값만 인정한다. 임의 주소를 넣으면 무시하고 원래 화면으로 간다(테스트로 확인).
3. **입력 최소화:** 끝 날짜처럼 처음 쓰는 사람이 헷갈리는 칸은 묻지 않고 합리적인 기본값(1년 뒤)을 넣는다.
