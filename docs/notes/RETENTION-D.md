# 가입 뒤 이어서 쓰게 하기 (PRD 4.11)

## 바뀐 것
- `fragments/ui.html` push 조각: 홈에서 문구를 "일요일마다 이번 주 근무 일수를 알려드릴까요?"로, 닫기 버튼을 "나중에"로 바꿨다. 누른 시각을 `localStorage`에 저장해 7일 동안 숨긴다.
- `home.html`: 알림 카드를 맨 아래에서 "오늘 기록" 바로 아래로 올렸다. 페이슬립 입구를 ③단계와 첫 근무 뒤에 추가했다.
- `work.html`: 일터가 있으면 페이슬립 링크를 보여준다.

## 핵심 코드 (면접 대비)
```
브라우저(localStorage 'whv88.pushClosed' = 누른 시각 ms)
        │ 홈이 열릴 때
        ▼
closed()?  지금 - 저장한 시각 < 7일 → 카드 숨김
           아니면 → 구독 상태 확인 → 안 받는 중이면 카드 표시
```
- 서버는 바뀐 게 없다. "7일 숨김"은 브라우저에만 저장해서 DB·개인정보가 늘지 않는다.
- 옛 값 '1'(영구 닫음)은 숫자 시각이 아니라서 한 번 다시 보이고, 그 뒤부터 7일 규칙을 따른다.

## 검수
- 테스트 122개 통과. `HomeWorkPagesTest`에 페이슬립 입구 3곳 확인을 추가했다.
- 알림 카드는 브라우저 스크립트라 서버 테스트로는 못 본다. 배포 뒤 폰에서 직접 확인한다.
- 보안: 새 입력·새 주소 없음. 페이슬립 링크는 기존 로그인 필요 화면으로만 간다.
