개인정보처리방침

"워홀 88"(이하 서비스)은 호주 워킹홀리데이 세컨·서드 비자 인정 근무를 기록하고 계산하는 개인 운영 서비스입니다. 서비스는 계산에 꼭 필요한 정보만 받고, 이용자가 원하면 언제든 지웁니다.

1. 받는 정보와 쓰는 곳

  • 구글 로그인 정보: 구글 계정 고유번호, 이메일, 이름 → 로그인과 본인 기록 구분
  • 근무 기록: 일터 이름, 포스트코드, 업종·작업 종류, 근무 기간·날짜·시간 → 인정 일수 계산
  • 비자 정보 (선택): 1년차 비자 만료일, 여유 일수 → 남은 기간 계산
  • 페이슬립에서 읽은 값 (선택): 고용주 이름, ABN, 급여 기간, 총 근무 시간, 고용 형태, 체크리스트 응답

받지 않는 정보: 페이슬립 원본 파일, TFN(세금번호), 계좌번호, 급여 금액, 여권번호. 페이슬립 PDF는 이용자 기기(브라우저) 안에서만 읽고 서버로 보내지 않습니다. 근무 이력 PDF에 넣는 영문 이름은 PDF를 만들 때만 쓰고 저장하지 않습니다.

2. 보관 기간과 지우는 방법

탈퇴할 때까지 보관합니다. 내 계정에서 탈퇴하면 계정과 모든 근무 기록을 바로 지웁니다. 서버 백업에 남은 사본은 최대 14일 안에 자동으로 지워집니다.

3. 다른 곳에 주는 정보

이용자 정보를 팔거나 광고에 쓰지 않으며, 법에 따른 요청이 아니면 다른 사람에게 주지 않습니다.

4. 맡기는 곳 (국외 보관)

  • Google Cloud (미국 오리건 서버): 서비스 서버와 데이터베이스 보관
  • Google: 구글 로그인 인증
  • GoatCounter (방문 통계): 어떤 화면을 몇 번 봤는지, 어느 사이트에서 왔는지, 브라우저·화면 크기·국가. 쿠키를 쓰지 않고, 이름·이메일·근무 기록 같은 개인정보는 보내지 않습니다. IP 주소는 저장하지 않습니다.

데이터는 인터넷 연결 시 HTTPS로 암호화해서 주고받습니다.

5. 쿠키

로그인 상태 유지를 위한 쿠키만 씁니다. 광고 쿠키는 쓰지 않고, 방문 통계(GoatCounter)도 쿠키 없이 셉니다.

6. 이용자 권리

언제든 내 기록을 보고, 고치고, 지울 수 있습니다. 탈퇴로 모든 정보를 지울 수 있습니다.
